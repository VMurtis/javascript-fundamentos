# JavaScript Fundamentos

## 📚 Sobre o projeto

Este repositório reúne exemplos práticos desenvolvidos durante os estudos dos fundamentos da linguagem JavaScript.

O objetivo é praticar os principais conceitos da linguagem por meio de exemplos simples e comentados, facilitando a revisão e a evolução dos estudos.

## 🧠 Conteúdos estudados

Durante o curso, foram trabalhados conceitos como:

* Variáveis com `var`, `let` e `const`
* Escopo de variáveis
* Tipos de dados
* `undefined` e `null`
* Strings e manipulação de textos
* Template strings
* Conversão de tipos
* Operadores aritméticos
* Operadores de comparação
* Operadores lógicos
* Valores `Truthy` e `Falsy`
* Estruturas condicionais `if` e `else`
* Funções
* Parâmetros e argumentos
* `return`
* Function Declaration
* Function Expression
* Arrow Functions
* Retorno implícito

## 🌱 Objetivo

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento de software, com foco na construção de uma base sólida em JavaScript.

Os códigos possuem comentários e explicações para facilitar a compreensão dos conceitos e servir como material de consulta durante os próximos estudos.
